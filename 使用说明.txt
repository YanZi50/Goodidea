【如何开始】
1. 解压本 zip 到任意文件夹
2. 双击 goodidea.exe 启动（无需安装）

【首次使用必做：配置 AI 模型】
软件本身不带模型，需要接入你自己的大模型 API：
  设置 → 模型管理 → 添加模型档案：
  · 名称：任意，如「Deepseek」
  · 接口地址：模型服务商提供的 API 地址
    （DeepSeek 官方：https://api.deepseek.com
      火山引擎/中转站：按服务商提供的地址填）
  · 模型名：如 deepseek-v4-flash / deepseek-chat / gpt-5 等
  · API Key：在模型服务商官网（如 platform.deepseek.com）
    创建，形如 sk-xxxxxxxx
  · 保存后点「测试连接」确认绿色可用 → 设为当前模型

【功能一览】
  · 文档库：导入脚本/文案（txt、md、docx），自动分块、
    智能分类建组、全文搜索、批量删除
  · 智能分析：按全部/分组/单篇分析知识库，输出行业洞察
  · 生成工作台：选技能模板 + 引用分组素材 + 热点参考，
    一键生成脚本（支持 A/B/C 三版），查重防雷同
  · 实时热点：热门话题自动刷新，可一键接入生成
  · 消耗统计：当日/按模型的 token 费用实时显示

【常见问题】
1. Windows 提示「未知发布者」：
   → 点「更多信息」→「仍要运行」（未签名软件的正常提示，
     放心使用）
2. 启动白屏 / 提示缺少组件：
   → 下载安装微软 WebView2 Runtime（搜索 WebView2
     Runtime 官网安装后重开）
3. 数据存在哪：
   → 本机 C:\Users\你的用户名\AppData\Roaming\
     com.goodidea.app\goodidea.db（每台电脑独立，
     互不干扰；可在软件内「导出备份」迁移数据）
4. 生成的文案没反应：
   → 检查模型档案「测试连接」是否通过、是否已设为当前模型

【系统要求】
  Windows 10 / 11（64 位）
